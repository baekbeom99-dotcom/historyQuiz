# 초등 5학년 사회 - 조선 시대 문화 퀴즈 웹앱 🎓

> 🌐 **실시간 웹앱 주소**: [https://baekbeom99-dotcom.github.io/historyQuiz/](https://baekbeom99-dotcom.github.io/historyQuiz/)

초등학교 5학년 사회과 교육과정(조선의 발전과 민족 문화)에 맞춘 반응형 퀴즈 웹 애플리케이션입니다.  
교실 전면 TV, 전자칠판, 태블릿, 학생 개인 스마트폰 등 다양한 기기에서 또렷하게 실행할 수 있도록 제작되었습니다.

---

## 📌 주요 특징 및 기능

1. **초등 5학년 2학기 사회과 핵심 10문제 수록**
   - 훈민정음 창제 (세종대왕)
   - 앙부일구 (해시계)
   - 측우기 (세계 최초 강우량 측정기)
   - 조선왕조실록 (유네스코 세계기록유산)
   - 풍속화 (김홍도, 신윤복)
   - 동의보감 (허준)
   - 거중기 (정약용, 수원 화성)
   - 조선왕조의궤 (궁중 기록화)
   - 대동여지도 (김정호)
   - 온돌 (전통 가옥 난방 방식)

2. **한 문제씩 집중 풀이 & 즉각적인 피드백**
   - 4지선다형 객관식 보기
   - 보기를 클릭하자마자 정답/오답 즉시 시각적 강조 (초록색 체크 / 빨간색 오답 표시 및 정답 유도)
   - 초등학생 눈높이에 맞춘 1~2문장의 쉬운 해설 표시

3. **교실 TV & 스마트폰 가독성 최적화**
   - **글자 크기 조절 기능 (A- / 보통 / A+)**: 대형 교실 TV나 뒷자리 학생도 선명하게 볼 수 있도록 폰트 스케일링 지원
   - **고대비 색상 설계**: 교실 형광등 조명 아래에서도 반사 없이 또렷하게 읽히는 선명한 텍스트 배색
   - **터치 친화적 UI**: 스마트폰이나 태블릿에서도 쉽게 누를 수 있는 넉넉한 버튼 크기(최소 60px 이상)

4. **웹 오디오 기반 효과음 & 축하 애니메이션 (완전 오프라인 작동)**
   - 외부 파일 없이 브라우저 자체 Web Audio API로 구동되는 정답(딩동댕🔔), 오답(띠로리🎵), 팡파레 효과음
   - 정답 및 최종 결과 달성 시 캔버스 폭죽(Confetti) 효과
   - 수업 상황에 맞춰 효과음 켜기/끄기(🔊/🔇) 원클릭 토글

5. **결과 화면 & 복습 기능**
   - 100점 만점 기준 점수와 맞힌 문제/틀린 문제 수 집계
   - 점수별 조선 시대 명예 칭호 부여 (👑 장원급제 대제학, 📜 암행어사, 📖 성균관 유생, 🌱 문화 탐험 꿈나무)
   - **'전체 해설 및 오답 복습하기'**: 내가 고른 답과 실제 정답, 해설을 한눈에 다시 보며 수업 마무리 정리 가능
   - **'다시 풀기'** 버튼으로 언제든 처음부터 재도전 가능

## 🚀 실행 방법

### 1) 바로 열기 (가장 간편한 방법)
- `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 웨일(Whale), 사파리(Safari) 등 웹 브라우저로 바로 엽니다.
- 별도의 프로그램 설치나 인터넷 연결 없이도 오프라인 환경에서 100% 정상 작동합니다.

### 2) 교실 수업용 로컬 서버로 열기 (선택 사항)
스마트폰이나 태블릿과 동일한 와이파이(Wi-Fi) 망에서 공유하고 싶다면 터미널에서 아래 명령을 실행할 수 있습니다:
```bash
# Python 내장 서버 실행
python -m http.server 8080
```
이후 브라우저에서 `http://localhost:8080` (또는 교사 PC의 IP 주소)로 접속하면 교실 내 모든 기기에서 접속 가능합니다.

## 🛠️ 문제 추가 및 수정 방법

문제를 수정하거나 새로운 퀴즈를 추가하고 싶다면 `quiz-data.js` 파일을 열어 다음 형식으로 수정할 수 있습니다:

```javascript
{
  id: 11,
  category: "주제 분류명",
  question: "문제 질문을 입력하세요",
  options: [
    "1번 보기",
    "2번 보기",
    "3번 보기",
    "4번 보기"
  ],
  answer: 0, // 0 = 1번 보기, 1 = 2번 보기, 2 = 3번 보기, 3 = 4번 보기
  explanation: "초등학생 눈높이에 맞춘 1~2문장의 쉬운 해설을 적어주세요."
}
```
